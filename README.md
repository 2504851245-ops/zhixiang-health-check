# 知衡 · 健康体检小站

一个无需安装、无需后端、可直接在浏览器中使用的个性化健康自查与体检沟通工具。

## 直接使用

双击 `index.html`，或将它拖入 Safari、Chrome、Edge 等现代浏览器。手机使用时，建议把整个文件夹放到静态网站服务中，再通过网址访问。

网站不需要注册。健康答案只在当前页面内参与计算，不会提交到服务器，也没有接入统计、广告或第三方脚本。刷新或关闭页面后，答案会被清除。

## 发布给家人朋友

这是纯静态网站，只需要上传 `index.html`、`styles.css` 和 `app.js`。

### 方法一：GitHub Pages

1. 在 GitHub 新建一个公开仓库。
2. 上传本文件夹中的 `index.html`、`styles.css`、`app.js`。
3. 打开仓库 `Settings` → `Pages`。
4. 在 `Build and deployment` 中选择 `Deploy from a branch`。
5. 分支选择 `main`，目录选择 `/ (root)`，保存。
6. 等待约 1 分钟，通过 GitHub 提供的网址访问。

### 方法二：Netlify Drop

1. 打开 [Netlify Drop](https://app.netlify.com/drop)。
2. 将整个 `outputs` 文件夹拖入页面。
3. 获得一个可分享的网址。

如果使用自己的域名、医院或机构官网，也可以直接把三个静态文件交给网站管理员部署。

## 内容与安全边界

- 问卷覆盖基础信息、既往疾病与近期指标、家族史、警示症状、生活方式和已有筛查经历。
- 结果按“先处理警示症状、近期重点检查、基础健康档案、年龄与风险筛查”分层生成。
- “关注指数”表示本次回答中识别出的关注线索数量，不是患病概率，也不是机器学习预测分数。
- 网站不提供疾病诊断、处方或治疗计划，不替代医生查体、检验报告解读和专科随访。
- 页面已提示：急性胸痛、严重呼吸困难或疑似脑卒中应立即拨打 120。

公开面向较大人群前，建议请具备资质的全科、健康管理或相关专科医生审核文案与筛查年龄边界，并按所在地区指南进行本地化。

## 如何修改

- 文案、问题和页面结构：`index.html`
- 视觉、响应式与打印版式：`styles.css`
- 问卷读取、规则判断和结果生成：`app.js` 中的 `calculateResult()`、`buildCheckupCards()`、`buildActions()` 和 `buildDoctorQuestions()`

修改筛查规则时，请同时更新页面中的“参考了什么”以及医疗边界说明。
